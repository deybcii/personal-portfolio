# Dave Brian Quinzon, Portfolio

Personal portfolio site for Dave Brian Quinzon, Real Estate and E-commerce Virtual Assistant, with automation work in GoHighLevel and n8n.

Built with Next.js 14, React, and plain CSS.

## Projects

1. Metro Realty Group GoHighLevel system: demo build with a sample business, not paid client work. Funnels, pipelines, calendars, and workflow automation.
2. My Reply Tracker: n8n demo build that filters job application replies and logs them to Google Sheets.
3. Metro Realty Lead Capture: n8n demo build with a webhook form, Sheets logging, and owner notification.
4. REVA coursework projects: 6 hands-on coursework projects, not program completion.
5. Milo's Space Adventure: a 17-page story coloring book for ages 2 to 5, sold as a print-ready PDF.

## Run it locally

npm install
npm run dev
